# 📊 PhonePe Business Analytics Dashboard

## 🔍 Overview
This project presents an end-to-end analysis of digital financial transactions inspired by PhonePe services. The objective is to monitor transaction performance, identify failure patterns, and generate actionable insights to improve system efficiency and user experience.

## 🎯 Problem Statement
Digital payment platforms handle millions of transactions daily. Even a small failure rate can impact user trust and revenue.
This project aims to **analyze transaction data to identify failure causes and optimize overall performance**.

## 🛠️ Tools & Technologies
* Microsoft Excel → Data Cleaning & Preprocessing
* Power BI → Dashboard Development & Visualization
* DAX → KPI & Measure Calculations

## 📌 Key Insights

* **High Success Rate (>95%)** indicates strong platform reliability
* **Server Errors are the primary failure cause**, requiring backend optimization
* **User-related issues (Incorrect PIN, Insufficient Balance)** also contribute to failures
* **Peak activity observed during mid-year months**, suggesting seasonal trends
* **Payments & Transfers dominate transaction volume**, forming the core business
* **Loans & Insurance provide strategic value despite lower usage**

## 📌 Conclusion
The analysis highlights a highly reliable digital payment system with strong adoption across core services. However, reducing transaction failures—especially those caused by server issues—can significantly improve user experience and platform efficiency.

## 🚀 Recommendations
* ⚙️ Improve backend systems to reduce server failures
* 🔐 Enhance user validation to minimize input errors
* 📈 Optimize infrastructure during peak usage periods
* 🎯 Promote high-value services like Loans & Insurance
* 📊 Continuously monitor KPIs for performance improvement
